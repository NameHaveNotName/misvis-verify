# sample_output

This directory contains **SYNTHETIC TEST DATA ONLY**.

- `synthetic_input/` — synthetic participant JSON exports generated by `analysis/generate_synthetic_data.py`
- `trials.csv` / `participants.csv` — CSVs produced by `analysis/prepare_data.py` from the synthetic input
- `validation_report.txt` — validation output from `prepare_data.py`
- `SYNTHETIC_EXAMPLE.json` — a single hand-written example

None of these files are real participant data. They are test fixtures used to verify
the JSON → CSV pipeline and must never be included in any analysis of real data.
